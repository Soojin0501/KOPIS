- 어느 방식이든 씨앗을 바꾸면 조합이 절반 넘게 달라진다. 둘째 장르의 근거가 약하기 때문이다.

## ⑥ 판정

### 표 7. 복합과 단일의 평균

| 벌 | 복합 | 단일 | 차이 |

| 보고서 | 51.98 | 45.06 | +6.92 |

| `as_run` | 46.78 | 45.06 | +1.72 |

보고서의 값은 `saved_2025` 로 정확히 재현된다. 이 벌은 유료 복합 공연만 다른 점수 파일을 썼다. 그 파일의 점수는 가격 축 없이 참여도와 규모만으로 계산됐고 평균이 7.7점 높다. 단일 공연과 유료가 아닌 복합 공연은 세 축을 모두 썼다.

같은 공식으로 맞추면 복합과 단일의 차이는 1.72점으로 줄거나 사라진다.

### 장르 조합 비교와 성공률

한 행은 공연장 규모와 장르 조합의 묶음이다. 복합 조합의 평균 점수가 두 단일 장르 평균의 평균 이상이면 성공이다.

| 벌 | 유료 성공률 | 무료 성공률 |
|---|---|---|
| 보고서 | 37.7% | 40.4% |
| `saved_2025` | 62.3% (33 / 53) | 59.6% (28 / 47) |
| `as_run` | 37.7% (20 / 53) | 59.6% (28 / 47) |
| `as_reported` | 30.2% (16 / 53) | 66.0% (31 / 47) |

- 2025년에 저장한 비교표는 `saved_2025` 로 정확히 재현된다. 53행과 47행의 점수와 판정이 모두 같다.
- 보고서의 두 값은 저장한 비교표의 **실패 비율**과 같다. 보고서의 뒤 절은 유료 실패 20행, 무료 실패 19행을 분석한다. 실패가 20행이면 성공은 33행이다.
- 무료는 어느 벌에서도 성공률이 40.4% 가 나오지 않는다. 보고서의 무료 성공률은 실패 비율을 잘못 적은 것이다.
- 유료는 공식을 통일하면 성공률이 37.7% 다. 보고서의 숫자와 같지만 우연이다. 보고서가 분석한 실패 20행과 맞지 않는다.

- 공식을 통일한 `as_run` 에서는 유료 실패가 33행이고 전환 비율이 72.7% 다.
